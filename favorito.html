Criar projeto de implantação direto do negócio

Na tela de um negócio ganho no Moskit, um clique abre o formulário do projeto já preenchido com os dados do negócio. Escolha uma das opções abaixo (a extensão é a mais prática; o favorito serve para quem não conseguir instalar).

Opção 1 — Extensão (botão direto na tela do negócio)

Instalação manual, uma vez por computador. Funciona no Chrome e no Edge.

Passo 1 — Baixar e extrair

  1. Clique em Baixar a extensão (.zip) e salve o arquivo.
  2. Abra a pasta onde ele foi salvo (normalmente Downloads), clique com o botão direito em extensao-moskit.zip e escolha Extrair Tudo… → Extrair.
  3. Mova a pasta extraída para um lugar fixo, por exemplo Documentos. Se o navegador reclamar de arquivos ao carregar (pode acontecer com pastas sincronizadas pelo OneDrive), use uma pasta local simples, como C:\extensoes\extensao-moskit.
Não apague nem mova essa pasta depois de instalar: o navegador usa os arquivos dela. Se apagar, a extensão para de funcionar.

Passo 2 — Instalar no Chrome

  1. No Chrome, digite chrome://extensions na barra de endereço e tecle Enter.
  2. Ative a chave Modo do desenvolvedor (canto superior direito).
  3. Clique em Carregar sem compactação (canto superior esquerdo).
  4. Na janela que abrir, escolha a pasta que contém o arquivo manifest.json e clique em Selecionar pasta. Essa janela mostra só pastas, nunca arquivos — por isso ela parece vazia, e é normal. Para ter certeza de qual pasta é a certa, abra-a antes no Explorador de Arquivos: ela deve mostrar manifest.json, content.js e LEIA-ME.txt. Se, depois de extrair, houver uma pasta extensao-moskit dentro de outra igual, a certa é a de dentro. Se o Chrome disser que o manifesto está ausente, você selecionou a pasta de fora.
  5. Confirme que apareceu o cartão Londrisoft - Criar projeto de implantação, com a chave ligada.

Passo 2 — Instalar no Edge

  1. No Edge, digite edge://extensions na barra de endereço e tecle Enter.
  2. Ative a chave Modo de desenvolvedor (menu à esquerda, na parte de baixo).
  3. Clique em Carregar descompactado.
  4. Na janela, escolha a pasta que contém o arquivo manifest.json e clique em Selecionar pasta (mesma observação do Chrome acima: a janela mostra só pastas).
  5. Confirme que apareceu Londrisoft - Criar projeto de implantação, ligada.

Passo 3 — Usar

  1. Abra no Moskit um negócio que já está Ganho.
  2. No canto inferior direito da tela aparece o botão azul Criar projeto de implantação (se não aparecer, atualize a página com F5).
  3. Clique nele: abre uma janela pequena com o formulário já preenchido.
  4. No primeiro uso, clique em Entrar com Google e escolha seu e-mail da empresa (@londrisoft.londrina.br). Nas próximas vezes entra direto (a sessão dura cerca de 12 horas).
  5. Confira os dados, ajuste os itens se precisar e clique em Confirmar e criar projeto.
Se o navegador avisar sobre “extensões no modo do desenvolvedor” ao abrir, é normal nessa instalação manual: feche o aviso (não desative a extensão).

Opção 2 — Favorito (não instala nada)

Para quem não conseguir instalar a extensão. Funciona no Chrome e no Edge.

Passo 1 — Criar o favorito

  1. Mostre a barra de favoritos: tecle Ctrl + Shift + B.
  2. Arraste o botão abaixo (clicando e segurando) para a barra de favoritos:

Passo 2 — Usar

  1. Abra no Moskit um negócio que já está Ganho.
  2. Clique no favorito Criar projeto de implantação na barra de favoritos.
  3. Abre uma janela pequena com o formulário preenchido. No primeiro uso, entre com o Google da empresa.
Se a janela não abrir, o navegador bloqueou o pop-up: clique no ícone de pop-up bloqueado, no canto direito da barra de endereço, e escolha Sempre permitir pop-ups do Moskit.
